# TANTA — Tantangan Nyata

Versi PWA mobile-first untuk GitHub Pages.

## Isi
- Home
- Detail Tantangan 01
- Detail Tantangan 02 — Keluarga
- Tentang
- Status otomatis Mendatang / Mulai / Selesai
- Pemenang Tantangan 01: Jacob
- Tantangan 02 tidak memiliki pemenang dan tidak memiliki sistem klaim hadiah
- Waktu: Selasa, 29 September 2026 — 14.00–15.00 WIB
- Hadiah: Rpxxx
- PWA installable
- Offline cache sederhana melalui service worker
- Logo dan icon berbasis SVG, tanpa asset PNG/JPG
- Tanpa login, backend, database, atau server aplikasi

## Deploy GitHub Pages
Upload seluruh isi folder ini ke repository GitHub Pages.
Pastikan `index.html`, `manifest.webmanifest`, `sw.js`, `app.js`, `style.css`, `logo.png` berada pada folder yang sama.

## Tantangan
Edit `app.js` pada `const challenges = [...]` untuk menambah atau mengubah tantangan.
Status dihitung dari `start` dan `end`.

## Tantangan 02 — Keluarga
Mulai: Rabu, 30 September 2026 — 00.00 WIB.
Selesai: Infinity (tanpa batas waktu).
Hadiah: hubungan keluarga menjadi lebih erat.
Tantangan ini mengajak peserta mengucapkan "I love you" kepada setiap anggota keluarga, terutama ayah dan ibu. Tidak ada hadiah uang/barang dan tidak ada sistem klaim hadiah.
